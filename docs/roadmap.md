# Roadmap

This roadmap outlines the current direction for Explainit.

## Near term

- Improve ingestion reliability and observability
- Expand chat quality controls and response transparency
- Improve onboarding flow for first-time workspace setup

## Mid term

- Add stronger analytics for chat usage and source coverage
- Improve multi-chat and multi-project management workflows
- Provide easier embed and customization options

## Long term

- Broader deployment templates for common cloud providers
- Advanced governance controls for enterprise teams
- More extensible plugin and integration ecosystem

Roadmap items are subject to change based on user feedback and contributor priorities.
